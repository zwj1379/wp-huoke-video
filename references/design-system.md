# 设计系统 · 深色科技商务风竖屏信息图

## 画布

- 分辨率：1080 × 1920（9:16 竖屏）
- 帧率：30fps
- 时长：由 BGM 决定，`durationInFrames = 秒数 × 30`（向上取整）

## 背景（深色科技商务风）

- 纵向渐变：`#081226`（顶）→ `#0D2A55`（中）→ `#0A1E3E`（底）
- 科技网格：半透明白色细线网格，铺满全屏（`Background` 组件内绘制）
- 发光粒子：10 颗青色/白色光点（`#54D8FF` / `#8FE8FF` / `#FFFFFF`），
  缓慢上下浮动 + 呼吸发光，位置分布在画面中上部
- 底部光晕：蓝色径向光晕（`rgba(38,118,224,0.55)`）+ 底部青色渐变带，
  呼吸脉动（`opacity = 0.75 + 0.25*sin(frame/20)`）

## 主标题（文字主体浮雕 + 循环扫光）

- **填充**：白→浅蓝灰的纵向渐变（字面本身有立体感）：
  `#FFFFFF → #F0F6FE → #D9E7F8 → #BCCFEC → #93B2D9`
- **顶部受光棱线**：`-1px -1px 0 rgba(255,255,255,0.95)` 的高光
- **底部厚度**：逐层挤出深蓝 `#123A6B`（4~7 层，随字号缩放：
  `depth = max(4, round(titleFont*0.07))`）
- **蓝色描边**：细线 `1.5px #2F80ED`，仅勾字形轮廓，不参与浮雕
- **循环扫光**：青色高光带 `rgba(84,216,255,0.8)`，窄带
  （`transparent 40% → 高光 50% → transparent 60%`），
  往返扫过文字内部（`backgroundPosition = 100 + 100*sin(frame/14)`，周期约 2.9s）
- 字号按标题长度自适应：
  - `>12 字 → 70px`
  - `8~12 字 → 78px`
  - `≤8 字 → 96px`
- 入场：0~10 帧从 `scale(1.05)` 归位到 `scale(1)`

## 副标题（金色胶囊）

- 金色胶囊底 `#FFD100`，圆角 60，文字深蓝 `#0E53A7`，字重 800
- 字号：`>12 字 → 32px`，否则 `40px`
- 光效：`boxShadow: 0 10px 26px rgba(0,0,0,0.42), 0 0 24px rgba(255,209,0,0.25)`
- 入场：0~10 帧从 `scale(1.08)` 归位

## 信息卡片（白色圆角卡片）

- 卡片区：`top 500 → bottom 1642`，左右留白 70px，卡片间距 22px
- 分组数 2~5 组时自动均分卡片区高度（`cardH = (区间高 - (n-1)*间距) / n`）
- 卡片白底圆角，顶部是**黄色胶囊组标题**（`#FFD100` 底 + 深蓝字），
  组标题下方可选**备注**（组标题右侧小字或独立行，深蓝色）
- 要点条目：左侧要点名称（深蓝 `#0E53A7`），右侧强调值（金额/数字，蓝底胶囊或加粗蓝色）
- 条目太多时字号自动缩小（按卡片高度计算 `itemFont`）
- 入场：错峰快速归位（卡片按 index 错开 3 帧，10 帧内 `translateY(26→0)`）

## 底部引导（弧形文字 + 循环律动）

- 底部弧形 SVG 路径排布，文字 44px，金色/白色描边
- 循环律动：`sin(frame/8)` 驱动
  - 上下浮动 ±5px
  - 缩放脉动 ±2.5%
  - 光晕呼吸（`opacity 0.82±0.18`）
- 文案长度控制：**12~14 字以内**，过长会溢出弧形

## 合规红线

- 「评论」等敏感词一律改写为「平论」或「留言」
- 涉及金额/政策的内容必须与用户原文一致，不得虚构数字
