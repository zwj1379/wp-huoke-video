# wp-huoke-video

> **WorkBuddy Skill · 文案转竖屏 9:16 信息图短视频（5 套模板）**

把一段未排版的文案（补贴政策、产品卖点、活动规则、知识科普等）一键生成竖屏 9:16 信息图短视频。内置 5 套模板，覆盖商务 / 政策 / 证据三大风格。

---

## 🎬 5 套模板

| ID  | 名称 | 风格 | 适用场景 |
| --- | --- | --- | --- |
| 1   | 深色科技·信息卡片版 | 深蓝科技 + 白卡分组 | 默认款，通用卖点 |
| 2   | 星空黄卡·键值清单版 | 星空 + 键值对 | 金额 / 数字强调 |
| 3   | 星空卡片·政策条列版 | 6~8 个胶囊卡片 | 政策条列、长要点 |
| 4   | 红色放射·补贴强调版 | 红金喜庆 + 金色碎屑 | 补贴 / 福利强吸睛 |
| 5   | 证据型·回单说服版 | 凭证区 + 攻略区 | **需用户上传图片**（依赖图片素材触发） |

---

## 📦 安装到本机 WorkBuddy

```bash
git clone https://github.com/zwj1379/wp-huoke-video.git \
  ~/.workbuddy/skills/wp-huoke-video
```

之后在 WorkBuddy 对话里以 `wp-huoke-video` 名称调用即可。
